# Creative Search Plugin Design Tokens

## Colors

| Token | Value | Usage |
|---|---|---|
| `--color-primary` | `#3b82f6` | Primary actions and links |
| `--color-accent` | `#8b5cf6` | Accent, branding gradient |
| `--color-secondary` | `#ec4899` | Secondary brand accent |
| `--color-success` | `#22c55e` | Online/healthy indicators |
| `--color-error` | `#ef4444` | Offline/error indicators |
| `--color-warning` | `#f59e0b` | Loading/transition states |
| `--color-text` | `#1a1a1a` | Primary body text |
| `--color-text-secondary` | `#666666` | Secondary/label text |
| `--color-text-tertiary` | `#999999` | Muted/timestamp text |
| `--color-surface` | `#ffffff` | Card/panel backgrounds |
| `--color-surface-secondary` | `#f5f5f5` | Secondary surface (stats, cards) |
| `--color-surface-hover` | `#eeeeee` | Hover state for secondary surfaces |
| `--color-border` | `#e0e0e0` | Borders and dividers |
| `--color-on-primary` | `#ffffff` | Text on primary backgrounds |
| `--color-primary-hover` | `#2563eb` | Primary button hover state |

## Border Radius

| Token | Value | Usage |
|---|---|---|
| `--radius-sm` | `4px` | Buttons, tags, small elements |
| `--radius-md` | `8px` | Cards, panels, containers |
| `--radius-full` | `50%` | Circles, indicators |

## Spacing

| Token | Value | Usage |
|---|---|---|
| `--spacing-xs` | `4px` | Minimal gaps |
| `--spacing-sm` | `8px` | Button/tag gaps |
| `--spacing-md` | `12px` | Section padding |
| `--spacing-lg` | `16px` | Card padding |
| `--spacing-xl` | `24px` | Large panel padding |

## Typography

| Token | Value | Usage |
|---|---|---|
| `--typography-body-size` | `14px` | Main body text |
| `--typography-h2-size` | `28px` | Stat values |
| `--typography-h3-size` | `20px` | Section headings |
| `--typography-caption-size` | `11px` | Labels, timestamps, metadata |
| `--font-family-ui` | `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` | UI text |
| `--font-family-mono` | `monospace` | Code/commands |
