# Documentation Standards

Total Recall follows strict formatting guidelines for all `.md` files in the `docs/` directory.

## 1. Mandatory Header
Every file in `docs/` must begin with:
```markdown
# [Title]

- **Category**: [Architecture | API | Feature | Business | Roadmap]
- **Last Updated**: [YYYY-MM-DD]
- **SSOT**: [File Path or Service]
- **Summary**: [1-2 sentence overview]
```

## 2. Formatting
- Use Markdown headers (`#`, `##`, `###`) for hierarchy.
- Use `> [!IMPORTANT]` or `> [!CAUTION]` GitHub-style callouts for warnings.
- All file paths MUST be absolute from the repository root.
