# Total Recall release

Use this for package releases; ordinary feature commits use normal Git workflow. Read deploy ownership and the release checklist for this operation. Inspect current tree, canonical tracker, version and previous evidence before editing.

Use the sanctioned node for builds, suites and gates; verify immutable source/package identity, native isolated health/version, current frontend bundle and clean scaffold. Follow the verified auto-pull/deployment contract rather than inventing a deploy path. Keep external publication within the user's authorization; verify actual Git/npm outcomes and clean owned jobs.
