# Git Sentinel & Repo Watchdog

> Continuous repository auditor checking dirty worktrees, unpushed commits, and stale branches

## Installation

```bash
npx total-recall plugin install ./.agent/plugins/git-sentinel --link
```

## Features

- **Identifier**: `git-sentinel`
- **Version**: 1.0.0
- **SSSS Category**: `repo-audits`
- **CLI Command**: `npx total-recall git-sentinel`
