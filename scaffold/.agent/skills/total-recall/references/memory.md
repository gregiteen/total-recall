# Memory and instruction operations

`recall "query" --local` searches local metadata/body indexes; `--fast` retrieves an exact slug; `--semantic` explicitly uses provider-assisted retrieval. Read the CLI help for scope and output options. `remember <category> "content" --project|--global` validates canonical writes. `edit` and `forget` preserve validated write semantics. Never edit canonical vault files manually.

Context returns the complete required rule set, not just a relevance-ranked search result. Treat unknown applicability conservatively. Explicit budgets govern readiness. `context:universal` is a curated permanent bootstrap, not an automatic property of every global rule. Do not infer local applicability from global descriptive facts.

Use `compile` to rebuild instruction surfaces and indexes after externally maintained skill/rule sources change. Do not delete embeddings databases to force work. Inspect proposals through proposal operations; memory node enumeration excludes proposal documents. Embedding coverage counts eligible memory documents. SSSS registry/envelope validation and event receipts define persistence; projections are derived.
