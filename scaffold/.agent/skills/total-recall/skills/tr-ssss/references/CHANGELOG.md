# SSSS Changelog

## [v0.2.0] - 2026-06
- **Changed**: Stripped product-specific primitives (`meeting`, `event`, `crm`, etc.) from the core specification to enforce vendor-neutrality. Product primitives must now live strictly in host-level registries.
- **Added**: Upgraded Total Recall, UltraChat, and MUSE to v0.2.0 alignment.

## [v0.1.0] - 2026-05
- Initial Draft Specification.
- Defined VFS primitives, Operation Contract, and Append-Only Event Graph.
