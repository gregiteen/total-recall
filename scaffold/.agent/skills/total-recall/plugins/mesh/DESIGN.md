# Mesh Network Atlas

Use the tone of a field atlas. The ink surface holds a persistent control strip and a quiet roster of machines. Use a serif title, plain sans-serif labels, and monospace for a verified address, command, or timing. Use warm warning colors only when an observation needs attention.

In Machines, let the roster and reachability ladder share a row at wide widths and stack in that order in a drawer. The ladder keeps control membership, path, login, and execution distinct. State words accompany any color or border changes. Separate recorded facts and their timestamps from current observations. A sleeping or offline device is different from a peer whose path failed a probe.

Flows, Placement, Boundary, and Join use the same map vocabulary. Give each source its own timestamp and unavailable state. The control strip distinguishes credential presence in Auth from a verified control API. Request fleet execution explicitly. The enrollment workflow hands key issuance to an interactive terminal.

Keep targets at least 44 pixels tall. Preserve keyboard focus on refresh, use a visible outline, and announce read failures through the status region. Layout changes need no animation. The [platform map](docs/MESH_PLATFORM.md) records what the current owner commands can observe.
