# tr-plugin-cli-agents Projects

Project documentation and tracking for the `cli-agents` plugin.

## One Active Project, By Rule

A new folder under `in-progress/` may only be created by the active plan naming it as a successor, or by Greg. Workstreams live inside the active plan; a folder is not a workstream.

## Mandatory 5-File Lifecycle

Every project adheres strictly to the sequential five-file specification order:
1. `AUDIT.md` (evidence-based audit and test baseline must be complete first)
2. `PRD.md` (requirements derived from audit findings)
3. `ARCHITECTURE.md` (system boundaries and token contracts)
4. `DEVELOPMENT_PLAN.md` (phased implementation tasks)
5. `PROJECT_TRACKER.md` (task checklists and append-only Action Log)
