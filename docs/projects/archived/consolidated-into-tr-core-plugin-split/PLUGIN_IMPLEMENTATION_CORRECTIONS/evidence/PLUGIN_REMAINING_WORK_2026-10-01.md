## Shared boundaries to freeze before fan-out

1. **Host state port:** one supported injected SSSS operation/query interface, owned extension registration, authorization/principal binding, event envelope, idempotency key and restart/replay semantics. Reject missing ports explicitly. Do not invent an adapter signature or use raw Markdown/JSONL writes as canonical persistence. Artifact bytes may use an authorized blob port; artifact metadata/events use operations.
2. **Host secrets/config port:** server-side supported resolver, explicit unavailable failure, redacted errors, provider endpoint/model/project bindings from configuration. Shared credential values are permitted; scope and disclosure determine correctness.
3. **CLI contract:** inspect actual host invocation before changing argv slicing. Preserve human/JSON exit parity, unsupported nonzero status, nested risk and dry-run controls, cancellation/timeouts and actual provider receipt status.
4. **Plugin UI port:** host-consumable manifest/export with authenticated queries/mutations/events, mount/update/teardown and empty/offline/error states. Plugin owners implement capabilities; Total Recall owns generic discovery/dispatch/rendering. No UI worker should invent this interface independently.
5. **Reusable dependencies:** phone/text share Telnyx concepts and compliance; phone/domains share pricing/branding; domains alerts depend on messaging/alerts; decision composer and design output share validated layout/artifact interfaces. Select one owner per shared module to prevent parallel conflicting copies.
