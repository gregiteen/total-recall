# UNIFORM_BRAIN_UPDATES — PRD

Project Prefix: `UNIFORM_BRAIN_UPDATES` · Kanban State: In Progress · Author: Codex · Date: 2026-10-13

One reusable command, `total-recall update --all-brains [--apply] [--json]`, updates both published packages across registered brains and installed plugins. Include nested consumers, preserve alias import names and dependency sections, pin one resolved release per package across the run, use the owning package manager, and independently verify actual installed metadata. Every consumer owns a local dependency installation. No vault, credential, Git or serving-process mutation.
