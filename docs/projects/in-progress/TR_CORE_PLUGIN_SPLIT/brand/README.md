# Brand options for the operated products

Three schemes per product. Each folder holds `logo.svg` (original mark) and `DESIGN.md` (palette with checked contrast, type, shape and density tokens from the card contract, voice, full feature list the card must expose, card layout, manifest tokens). `gallery.html` shows all nine side by side, including 16 px and dark-surface renderings and a header preview.

| Product | Options | Recommended |
| --- | --- | --- |
| Hello Phone (white, blue, yellow) | `bell`, `dialpad`, `wave` | `dialpad`: reads as a phone at a glance and the lit yellow key doubles as the live-call indicator |
| Mad Domains & Email (yellow, black, red) | `crown`, `mad-m`, `globe-flap` | `mad-m`: strongest at small sizes; use the crown as secondary artwork for "email empire" |
| Creative Search | `compass`, `trail`, `constellation` | `trail`: tells the agentic-browsing story, which separates it from ordinary search |

Marks are first drafts for direction. Final marks need a refinement pass and a trademark check before public use.
