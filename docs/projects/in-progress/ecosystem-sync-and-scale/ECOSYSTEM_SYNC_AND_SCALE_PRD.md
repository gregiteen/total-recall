# ECOSYSTEM SYNC AND SCALE: PRD

## Goal
Total Recall must evolve from a localized memory vault into a fully integrated, centralized ecosystem manager. It must autonomously manage repo-specific skills, embedded skills, automatic code examination (Crons), GitHub synchronization, Obsidian synchronization, and strict OKF/tr-ssss compliance across all registered brains.

## Why this matters for the OS
The system currently experiences fragmentation. 404s appear on surface requests (recently fixed, but symptomatic of loose coupling), skills are disorganized between global and local domains, and the agent requires manual prompts rather than continuous background scanning (Crons). Synchronizing this via standard protocols (OKF and SSSS) hardens the memory system against corruption while providing true autonomous scale.

## Core Features
1. **Centralized Skill & Data Architecture**: Clear resolution paths for `global` vs `project` skills, and `embedded` (in-repo) vs `system` skills.
2. **Autonomous Code Crons**: Scheduled background tasks that examine code and auto-generate/update skills.
3. **GitHub Sync**: Push/pull memory nodes to GitHub repos for remote backup and collaborative memory.
4. **Obsidian Sync**: Two-way sync for the SSSS Markdown vault so users can edit memory in Obsidian natively.
5. **OKF & tr-ssss Compliance**: Fully strict SSSS compliance on all primitives generated by the system.
6. **System-wide Bug Triage**: Complete audit of all UI sections, data display grids, and API endpoints.

## Implementation Guidelines
- Follow Trunk-Based Development.
- All new sync modules (GitHub, Obsidian, Crons) must be feature-flagged or modularly added to the `src/core/` daemon without breaking the main loop.
- No direct database writes—everything remains VFS/Markdown.
