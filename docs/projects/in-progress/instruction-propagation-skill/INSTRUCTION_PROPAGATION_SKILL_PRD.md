# Instruction Propagation & Master Agent Skill PRD

- **Plane**: Product
- **Status**: In Progress
- **Created**: 2026-05-20
- **Owner**: Total Recall

## Summary

This Product Requirements Document (PRD) defines the specifications to resolve the lack of comprehensive local intelligence and domain tools for IDE-native AI agents running alongside the Total Recall Sovereign OS. 

Currently, when local agents boot within individual workspaces, they lack proper domain skills, system documentation, and self-healing heuristics. They are prone to hallucinating configuration files, missing active CLI tools, and violating Tier 1 memory invariants. 

We will solve this by implementing two core features:
1. **Universal Multi-IDE Instruction Propagation**: Ensuring every IDE rules file (shims such as `.cursorrules`, `CLAUDE.md`, `.clauderules`, `AGENTS.md`, `GEMINI.md`, and all subfolders) automatically receives a fully detailed, non-destructive, and comprehensive system guide.
2. **Master `total-recall` Skill Package**: Designing and seeding a dedicated local skill conforming to the universal skill spec, containing detailed codebase architecture maps, VFS topologies, SSSS v2 guidelines, CLI/REST API manuals, troubleshooting procedures, and an autonomous upstream repository synchronization mechanism.

---

## The Problem

A systematic audit of the current instruction injection and local IDE environment reveals critical architectural gaps:
1. **IDE Hallucinations**: Standard IDE agents have no knowledge of the underlying Total Recall VFS directory structure, background daemon cycle, or API specifications. When asked to debug or interact with the system, they hallucinate paths, write invalid memory schemas, or fail to find existing scripts.
2. **No Upstream Sync**: When memory conventions or system APIs are updated in the official repository, local workspaces have no programmatic way of pulling down the latest rule definitions, schema specifications, or skill upgrades.
3. **Incomplete Preamble shims**: Existing instruction-propagation scripts do not reliably inject the full instruction set into real, pre-existing IDE rules shims. Some are left with empty symlinks, while others receive only subset records, resulting in inconsistent compliance.
4. **Lack of Self-Healing**: IDE agents have no troubleshooting guides within their runtime prompt. When the brain connection fails, or a port conflict occurs, agents fail to help the developer resolve it.

---

## Goals

- **100% Shim Coverage**: Compile the absolute comprehensive guide directly into the managed memory injection block so that both symbolic links and pre-existing real shims receive the full instruction set non-destructively.
- **Dedicated Master Skill**: Create a native, seeded skill package under `.agent/skills/total-recall/` containing complete references, validation suites, and operational scripts.
- **Automated Upstream Sync**: Introduce a local synchronizer script (`scripts/sync-repo.mjs`) enabling local agents and users to sync their skill templates and invariants directly with the official repo.
- **Zero-Friction Scaffolding**: Integrate the master skill into workspace initialization pipelines (`init.mjs`, `connect.mjs`, and `deploy.mjs`) so it is seeded automatically upon deployment.
- **Self-Healing Guide**: Include active troubleshooting heuristics detailing how to resolve VFS conflicts, compiler blocks, and connection failures.

## Non-Goals

- Replacing the Markdown-native VFS storage with a traditional database.
- Modifying the core SSSS v2 YAML parser or node validation constraints.
- Re-architecting the remote UltraChat cloud synchronization fabric.

## Feature Specifications

### 1. Unified Comprehensive System Docs Preamble
The managed injection block (`<!-- BEGIN INJECTED MEMORY ... -->`) generated by `surface.mjs` will be enriched to include:
- **Core Concept**: What is Total Recall, how it functions.
- **Architectural Layout**: The Three-Tier Memory Hierarchy and VFS directory layout.
- **Tool Selection Heuristics**: Precise rules governing when an agent should use Local Skills (via command runner) vs. MCP Tools vs. Direct REST APIs.
- **Comprehensive REST API Reference**: Full cheat sheet of endpoints, parameters, and return types.
- **SSSS v2 Schema Specifications**: Exact fields and category taxonomies.
- **Self-Healing & Troubleshooting**: How to resolve daemon failures, PAT authentication bugs, port conflicts, and compiler errors.

### 2. The Master `total-recall` Skill
A complete, universal skill package located at `.agent/skills/total-recall/` containing:
- `SKILL.md`: The trigger-optimized, high-priority rule entry point.
- `references/architecture-reference.md`: Codebase topological overview, detailing directories, runtime processes, and database-free architecture.
- `references/cli-reference.md`: CLI tools command parameters and REST API references.
- `references/ssss-reference.md`: Structural SSSS v2 specs.
- `references/troubleshooting.md`: Step-by-step guides to diagnose and fix local setup errors.
- `scripts/sync-repo.mjs`: Script to automatically synchronize local `.agent/skills/` and `.agent/memory-vault/` with the official repository, updating rules and definitions based on upstream changes.
- `evals/evals.json`: Validation suite checking if `npx total-recall compile` runs correctly and if the `.agent/skills/total-recall` is sound.

### 3. Integrated Scaffolding & CLI Hooks
- Modify `src/cli/init.mjs` and `src/cli/connect.mjs` to automatically copy the `total-recall` skill folder from `scaffold/.agent/skills/total-recall` to local workspace directories.
- Register `--sync` option and subcommand hooks to trigger `scripts/sync-repo.mjs` via standard CLI calls.

## Success Metrics

1. **Perfect Propagation**: Run `npx total-recall compile` on a workspace with various pre-existing shim files (Cursor, Claude, VS Code, etc.) and verify that the managed injection block contains the complete comprehensive system guide.
2. **Zero Hallucination Benchmarks**: Local IDE agents can explain the entire architecture, correctly execute standard CLI commands (like `doctor`, `backup`, `status`), and diagnose errors using the local skill.
3. **Green Validation Suites**: Clean execution of code-quality check and TypeScript verification commands:
   - `node .agent/skills/code-quality/scripts/start-here-ts.mjs` returns `0 TS errors`.
   - `node .agent/skills/code-quality/scripts/start-here-lint.mjs` returns `0 lint problems`.
4. **Successful Sync execution**: Run `node .agent/skills/total-recall/scripts/sync-repo.mjs` and verify it pulls from the upstream repo and merges correctly.
