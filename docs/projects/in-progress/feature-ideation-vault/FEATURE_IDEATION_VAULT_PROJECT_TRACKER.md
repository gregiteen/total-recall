# Feature Ideation Vault — Project Tracker

> **Purpose**: An ever-growing, ever-refining catalog of feature ideas for Total Recall / SSSS. This is not a typical execution epic — it's a long-lived ideation surface. Each "phase" is a refinement pass that adds new ideas, deepens existing ones, kills duplicates, and promotes the strongest ones to real specs.

## Active Document
- [FEATURE_IDEATION_VAULT_IDEAS.md](./FEATURE_IDEATION_VAULT_IDEAS.md) — the master catalog

## Refinement Passes

### ✅ Phase 1: Pass 1 — Initial brain-dump
- [x] Seed 4 threads (Daily-Life Apps, User-Defined App Platform, UX Innovations, Inference-Budget Unlocks)
- [x] Add cross-cutting / meta thread (Thread E)
- [x] Each idea structured with: pitch, SSSS lever, sketch, value, open questions
- [x] Target: 30+ ideas

### ⏳ Phase 2: Pass 2 — Depth on existing ideas
- [ ] For each Pass 1 idea, deepen the SSSS-lever rationale
- [ ] Add concrete first-week implementation sketch for top 10
- [ ] Identify dependencies between ideas
- [ ] Identify which ideas compose into "killer demos"
- [ ] Net-add 10+ new ideas surfaced by deeper thinking

### ⏳ Phase 3: Pass 3 — Adversarial review
- [ ] For each idea, write its strongest critique
- [ ] Kill or merge ideas that fail the critique
- [ ] Flag ideas that need user input to survive
- [ ] Cluster surviving ideas into themes

### ⏳ Phase 4: Pass 4 — Cross-pollination
- [ ] Look for pairs of ideas that compose into a third, stronger idea
- [ ] Look for ideas that, combined, form a coherent product narrative
- [ ] Add "compositional ideas" section

### ⏳ Phase 5: Pass 5 — User journeys
- [ ] For each surviving idea, sketch the first-time-user moment that makes it land
- [ ] Identify which ideas require zero onboarding vs heavy setup
- [ ] Rank by "demoability"

### ⏳ Phase 6: Pass 6 — Effort & risk scoring
- [ ] Estimate engineering cost (S/M/L/XL) per surviving idea
- [ ] Estimate risk (technical / UX / philosophical)
- [ ] Score leverage = value / (effort × risk)

### ⏳ Phase 7: Pass 7 — Promotion candidates
- [ ] Identify top 3 ideas to promote to formal PRDs
- [ ] Draft one-paragraph PRD summaries for each
- [ ] Hand off to standard /project-management SWE lifecycle

### ⏳ Phase 8: Validation Pass
- [ ] Re-read entire document end-to-end
- [ ] Check for contradictions, redundancies, vague claims
- [ ] Verify every idea ties back to a structural SSSS lever
- [ ] Verify the "north star" section still reflects the catalog
- [ ] Confirm the document remains scannable at its current length

## Operating Rules
- **Never delete an idea** — mark it superseded, merged, or killed with reasoning.
- **Every pass adds AND refines** — pure addition without refinement is disallowed.
- **Each idea must name its SSSS lever** — if no lever, it's a generic AI feature and gets demoted.
- **Refinement Log inside IDEAS.md** records what changed each pass.
